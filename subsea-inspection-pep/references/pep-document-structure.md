# Common Subsea/Diving PEP Document Structure

Based on reviewed example PEPs from Shell/SPDC/SNEPCO projects (Atlantic Marine template family).

## Core Sections (in order)

| # | Section | Content |
|---|---------|---------|
| 1 | Abbreviations, Definitions & References | 20-30 acronyms, project-specific guidance docs |
| 2 | Introduction | Who contractor is, project overview, document purpose |
| 3 | Project Scope of Work | Broken into client-issued scope + contractor's scope breakdown |
| 4 | Asset Information | Location, water depth, environment, facility description |
| 5 | Vessel Information | DSV specs with key features table |
| 6 | Project HSE Guidelines | HIRA (3-stage), JSA, TBT, MOC, PTW, Fatigue, PPE, Pollution |
| 7 | Roles & Responsibilities | Role-by-role blocks (Authority + Responsibilities) |
| 8 | Organisation & Communications | Org chart (mermaid), comms protocol, reporting lines |
| 9 | Environmental / Weather Conditions | Climate, operational limits table, monitoring, seasonal planning |
| 10 | Mobilisation & Demobilisation | Equipment list, timeline, pre-mob inspection, de-mob punch list |
| 11 | Inspection / Execution Methodology | Per-task breakdown (GVI, Marine Growth, Anode, CP, UT, ACFM, etc.) |
| 12 | Special Operations (SIMOPS) | If working near producing facilities |
| 13 | Incident / Near-Miss Reporting | |
| 14 | Permits (PTW) System | Dual system: Client PTW primary, vessel PTW secondary |
| 15 | QA/QC | |
| 16 | Emergency Response | ERP reference, drill schedule, nearest hospital, medevac route |
| 17 | Appendices | Vessel spec sheet, org chart, CVs, ITP, risk register, community plan |

## Formatting Conventions (Atlantic Marine / Shell examples)

- **Header**: "Restricted" in red bold 9pt, ECCN notice in grey 7.5pt
- **Font**: Calibri 10.5pt body
- **Headings**: Dark blue (003366), bold
- **Table headers**: Dark blue fill, white bold text
- **Table body**: 9pt
- **Units**: Oil field Metric — put metric after imperial in brackets: 1000ft [305m]
- **Margins**: 2.0cm top/bottom, 2.5cm left/right
- **Revision labels**: P01 (preliminary), R01 (review), A01 (approved for implementation), Z01 (as-built)

## HIRA Pattern (common across all examples)

1. **Stage 1** — Office-based: High-level hazard identification pre-mob (management + client HSE)
2. **Stage 2** — Worksite-based: Task-specific risk assessment on vessel before first dive
3. **Stage 3** — Toolbox Talk: Per-shift, per-task JSA sign-off by all personnel

## NDT Decision Rules (Nigeria / Niger Delta)

- **Use ACFM** when SOW mentions poor/zero visibility or currents >1kt
- **MPI is unreliable** when visibility prevents particle pattern interpretation or currents >1kt wash particles away
- **FMD** as alternative to close visual inspection for preselected joints

## Weather Downtime Rules (Nigeria contracts)

- **Dry season (1 Nov – 1 May)**: All weather downtime is CONTRACTOR's cost
- **Wet season (2 May – 31 Oct)**: First 12hrs per shutdown is CONTRACTOR's cost, remainder is COMPANY's cost
- **Operational limits for air diving from moored DSV**: 1.0m swell, <10kts wind, 0.7kts current (typical)
- **Squall protocol**: 16nm radar watch, 10nm trigger for suspend, VHF reporting
